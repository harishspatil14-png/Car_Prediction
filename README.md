🚗 Car Price Prediction

📌 About the Project

Car Price Prediction is a Machine Learning web application that estimates the selling price of a used car based on its details. It provides a simple interface where users can enter vehicle information and receive an estimated price.

✨ Features

- Predicts estimated used car prices.
- Car company and model selection.
- Manufacturing year input.
- Kilometres driven input.
- Fuel type selection.
- Autocomplete and dropdown-based input options.
- User-friendly web interface.

🛠️ Technologies Used

- Python – Core programming language
- Flask – Web application backend
- Pandas – Dataset processing
- Scikit-learn – Machine Learning
- HTML – Web page structure
- CSS – User interface styling
- JavaScript – Frontend interactions

⚙️ Installation and Setup

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the project directory

cd Car_Price_Predictor

3. Create and activate a virtual environment (optional)

python -m venv .venv

Windows PowerShell:

.\.venv\Scripts\Activate.ps1

4. Install dependencies

pip install -r requirements.txt

5. Run the application

python app.py

Open the local URL displayed in the terminal in your browser.

🚀 How to Use

1. Start the application.
2. Select the car company and model.
3. Enter the manufacturing year.
4. Enter the kilometres driven.
5. Select the fuel type.
6. Submit the details to get the estimated car price.

🎯 Objective

The objective of this project is to apply Machine Learning to used-car price estimation and provide a convenient web application for users.
